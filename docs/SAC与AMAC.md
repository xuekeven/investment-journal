# SAC 与 AMAC

中国证券业协会（SAC）主要面向证券公司及证券业务，例如证券经纪、投资顾问、证券研究、投资银行和保荐；中国证券投资基金业协会（AMAC）主要面向基金与资产管理业务，例如公募基金、私募证券基金、私募股权基金、基金销售与基金服务。

两者都是接受中国证监会指导和监督的行业自律组织，但都不是中国证监会本身。

## 一、两家协会的区别

| 对比 | 中国证券业协会 | 中国证券投资基金业协会 |
| --- | --- | --- |
| 简称 | 中证协、SAC | 中基协、AMAC |
| 主要行业 | 证券行业 | 基金和资产管理行业 |
| 典型机构 | 证券公司、证券投资咨询公司、证券评级机构 | 公募基金公司、私募基金管理人、基金销售及服务机构 |
| 典型业务 | 证券经纪、投顾、研究、投行、保荐、融资融券 | 基金募集、投资管理、销售、托管、估值、登记、私募备案 |
| 考试名称 | 证券行业专业人员水平评价测试 | 基金从业资格考试 |
| 主要用途 | 证明具备相应证券业务的专业能力 | 满足基金从业资格注册条件 |
| 特有职能 | 证券公司及相关从业人员自律管理 | 办理私募基金管理人登记、私募基金备案等 |

中基协的职责包括基金行业自律、从业考试和资格管理，以及依法办理非公开募集基金的登记、备案。参见[中国证券投资基金业协会简介](https://www.amac.org.cn/gyxh/xhjs/)。

需要注意：通过考试通常不等于立即取得完整执业资格。真正执业时，一般还需要进入相应机构，由所在机构办理从业登记或资格注册。

## 二、基金从业资格考试

自 2026 年 9 月基金从业资格行业专场考试开始，考试按照《基金从业资格考试大纲（2026 年度修订）》组织。参见[中基协现行考试大纲](https://www.amac.org.cn/fwdt/wyb/rygl/cyks/cyksjcdg/jcksdg/202606/t20260630_27896.html)。

### 科目一：《基金基础知识与法律法规》

主要学习：

- 基金行业及基金参与主体
- 公募基金、私募基金基本制度
- 基金募集、销售、申购与赎回
- 基金份额登记、估值与核算
- 基金信息披露
- 投资者适当性管理
- 基金管理人的内部控制与合规
- 从业人员职业道德
- 《中华人民共和国证券投资基金法》及其配套规则

科目一以法规、业务流程和职业规范为主，需要准确理解和记忆。

### 科目二：《证券投资基金基础知识》

主要学习：

- 货币时间价值、复利、现值与终值
- 收益率、波动率、协方差与相关系数
- 股票、债券和基金估值
- 资产配置与投资组合理论
- CAPM、系统风险与非系统风险
- 久期、凸性与利率风险
- 期货、期权、远期等衍生工具
- 基金业绩评价
- 基金会计、估值与费用
- 境外投资与 QDII 基础

科目二的计算题和理解题更多，与个人进行基金投资、指数基金比较和资产配置的关系也最密切。

### 科目三：《私募股权投资基金基础知识》

主要学习：

- 私募股权基金和创业投资基金
- 募集、设立与备案
- 项目筛选与尽职调查
- 企业估值
- 投资协议和交易结构
- 投后管理
- IPO、并购、股权转让等退出方式
- 私募股权基金的法律、税务和监管制度

科目三偏向一级市场、股权投资和创业投资，不是普通证券投资基金知识。

### 科目选择

- 公募基金、基金销售、证券类私募：通常选择科目一加科目二。
- PE、VC、私募股权投资：通常选择科目一加科目三。
- 以提高个人基金投资能力为目的：建议学习科目一和科目二，并重点学习科目二。

基金从业资格考试通常采用闭卷机考，每科 120 分钟、100 道单选题，满分 100 分，60 分为合格线。具体安排以当期考试公告为准。参见[2026 年基金从业资格考试公告](https://www.amac.org.cn/xwfb/tzgg/202604/t20260427_27624.html)。

## 三、证券行业专业人员水平评价测试

目前准确名称是“证券行业专业人员水平评价测试”，不宜再笼统称为“证券从业资格考试”。

### 一般业务水平评价测试

一般业务水平评价测试包括两门基础科目。

#### 1.《金融市场基础知识》

主要学习：

- 中国金融市场体系
- 股票及股票发行交易
- 债券及债券市场
- 证券投资基金
- 金融衍生工具
- 资产证券化
- 金融风险管理
- 中央银行与货币政策
- 证券市场参与者及基础设施

该科目的覆盖面比基金科目二更广，但在投资组合和估值计算方面通常没有基金科目二深入。

#### 2.《证券市场基本法律法规》

主要学习：

- 《中华人民共和国证券法》《中华人民共和国公司法》等基础法律
- 证券公司设立与治理
- 证券经纪业务
- 证券投资咨询业务
- 证券承销与保荐
- 自营、资产管理、融资融券等业务规则
- 投资者适当性与投资者保护
- 从业人员执业规范
- 市场操纵、内幕交易等违法行为
- 合规管理、廉洁从业和纪律要求

自 2026 年 9 月 1 日起，《证券行业专业人员水平评价测试纪法知识大纲（2026）》纳入一般业务水平评价测试《证券市场基本法律法规》科目的测试范围。参见[中证协大纲公告](https://www.sac.net.cn/sjb/pxzx/pxzdydg/202606/t20260626_81842.html)。

### 专项业务水平评价测试

从事特定证券业务，还可能需要参加相应专项测试：

- 《证券投资顾问业务》：面向证券投资顾问。
- 《发布证券研究报告业务》：面向证券分析师。
- 《投资银行业务》：主要面向保荐代表人。
- 证券公司高级管理人员、合规管理人员等对应的水平评价测试。

一般先使《金融市场基础知识》和《证券市场基本法律法规》达到基本要求，再根据具体岗位准备专项测试。参见[证券行业专业人员水平评价测试实施细则](https://www.sac.net.cn/flfg/zlgz/202207/t20220711_54184.html)。

一般业务水平评价测试通常为每科 120 分钟、120 题，题型包括单选题、多选题、判断题和综合题，正确率达到 60% 以上视为达到基本要求。

报名资格和开放对象需以当期公告为准。统一测试通常面向符合报名条件的社会考生；专场测试和预约测试通常面向证券行业机构人员或特定人员。参见[2026 年证券行业专业人员水平评价测试问答](https://ks.sac.net.cn/sac/examMsg/showNotice.htm?id=159)。

## 四、如何选择

如果主要目的是学习证券和基金投资，而不是立即求职，推荐顺序是：

1. 《证券投资基金基础知识》
2. 《金融市场基础知识》
3. 《基金基础知识与法律法规》或《证券市场基本法律法规》

如果准备进入金融行业，可按目标岗位选择：

| 目标方向 | 建议学习或报考的科目 |
| --- | --- |
| 公募基金、基金销售、基金投研 | 基金科目一加科目二 |
| 私募证券基金 | 基金科目一加科目二 |
| PE、VC | 基金科目一加科目三 |
| 证券公司普通业务岗位 | 证券一般业务两门基础科目 |
| 证券投资顾问 | 证券两门基础科目加《证券投资顾问业务》 |
| 证券分析师 | 证券两门基础科目加《发布证券研究报告业务》 |
| 投行、保荐 | 证券基础科目加《投资银行业务》 |

对于指数基金、资产配置和投资复盘方向，最适合优先学习基金科目二《证券投资基金基础知识》。基金科目一和证券法律法规更偏向行业制度、业务规范与合规要求。
